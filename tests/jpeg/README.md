# JPEG recovery corpus

32 synthetic JPEGs, generated by `scripts/make_jpeg_corpus.py` with Pillow/libjpeg
and a small separate flat-block encoder. Each was reopened and fully decoded by
Pillow with truncated-image loading disabled. No third-party sample images or
user data are included. `manifest.json` records exact byte lengths and SHA-256.

Includes sequential and progressive L/RGB/CMYK, common subsampling, edge sizes,
optimized tables, restart intervals, true RGB, SOF1, 16-bit quantization,
separate-component sequential scans, marker fill and comments. A synthetic APP1
contains both a false EOI and an independently discoverable valid thumbnail.
That thumbnail is an additional candidate, not an additional original file.

`scripts/e2e_jpeg.py` uses the committed bytes with only Python's standard
library. It also generates malformed markers and entropy, checks CLI/MCP output
bytes, and tests mixed PNG, range/filter/ZIP/collision/source-change behavior.
These fixtures do not establish general recovery rates or physical disk behavior.
