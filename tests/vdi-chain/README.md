# VirtualBox differencing VDI references

Oracle VirtualBox 7.2.22 created three two- or three-generation NTFS chains and one three-generation FAT32 chain. The fixed base and dynamic bases were created with `vbox-img convert`. The capture program used the VirtualBox disk library to create each differencing child, write the changed sectors, and flush. It then reopened every generation read-only and compared every logical byte through Oracle's `VDRead` with the original guest.

For NTFS, the input is the complete logical disk of each generation previously captured through the Windows disk driver in [the VHD reference set](../vhd-chain). The fixed and two-child profiles have seven small deleted files. The flushed profile has seven larger files that Windows flushed before deletion. The FAT32 input was formatted with mkfs.fat. Its seven files were written and read back with mtools, then three and four were deleted in successive snapshots. Two witness blocks after the FAT32 volume exercise an explicit zero hiding a nonzero parent, inherited bytes and a partial-sector-range overwrite. Every VDI was produced by VirtualBox; the capture does not edit VDI metadata by hand.

The manifest records each complete container and guest SHA-256, guest size and allocation-table counts. The portable test checks every generation against the full original byte stream, recovers seven deleted files from each final guest through normal and indexed scans, and checks corrupted mappings, missing/wrong parents and incorrect expected hashes. A valid parent with unchanged IDs but altered data is distinguishable by a known guest SHA-256.

To regenerate a new set on Linux, run `python tests/vdi-chain/capture.py --vbox-img /path/to/vbox-img --output /path/to/empty-folder`. The executable should reside next to its own VBoxRT.so and VBoxDDU.so, with loadable dependencies. The FAT32 fixture additionally uses dosfstools and mtools. UUIDs and filesystem timestamps are newly generated. No VirtualBox software is needed to run Rescue or its portable test against the preserved reference files.
