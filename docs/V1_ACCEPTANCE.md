## OS試験の構成

Windows Server 2022 (x64)、Ubuntu 22.04 (x64)、macOS 26 (Intel/Apple Silicon) の
GitHub ActionsネイティブVMを使う。Linux上の外見だけを変更した環境で3 OS検証とはしない。
ホストの既存ディスクを初期化せず、この試験で作成・識別したVHD、loop、hdiutilディスクのみを操作する。

各OSで共通の正解付きRAWとCLI/MCPを検証し、OS固有の実ディスク読取・マウント・同一場所復元も実施する。
追加シナリオは、削除PDF、同名ファイル/フォルダー、長い日本語パス、アクセス拒否、空き容量不足、
操作取消、プロセス強制終了後の再開、読取不良、欠損RAIDメンバー、破損管理情報、UIのサイズ/DPI/キーボード。
合成障害と実OSの挙動、GUI自動操作と手動評価は報告上区別する。

## 公開の判定

必須機能を実装し、意味のある異常系と回帰試験を通し、実際に配布する署名・梱包後の実行ファイルを検証する。
未実装を「既知の制限」に移してv1.0を成立させない。対応形式の具体的なプロファイルと資源上限は明記する。
元データの正解ハッシュがない通常利用で、構造検証や出力ハッシュを削除前の同一性の証明とは表示しない。
