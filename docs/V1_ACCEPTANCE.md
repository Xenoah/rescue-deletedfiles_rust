## OS試験

Windows Server 2022 x64、Ubuntu 22.04 x64、macOS 26 Intel/Apple Siliconの
GitHub ActionsネイティブVMを使う。ホスト既存媒体を初期化せず、試験で新規作成・識別した
VHD、loop、hdiutil媒体だけを操作する。合成障害と実OSの挙動を区別する。

各OSでCLI/MCPの共通正解像、実仮想ディスク読取・取得・同じ場所への復元、削除PDF、
長い日本語パス、同名、容量不足、アクセス拒否、取消、強制終了後の再開を確認する。
GUIのモデル試験、実ウィンドウの自動操作、手動・支援技術製品の評価を混同しない。

## 公開判定

`assemble_release.py` は4環境のJSON、8パッケージ、GUIの版と画像ハッシュ、
`v1-readiness.json` の証拠ハッシュ、大容量完走、商用比較、通常権限Windows GUIを必須にする。
公開後は署名・梱包後の実行ファイルをダウンロードし、同じ正解ケースを再実行する。
Windowsでは公開GUIそのものを通常権限で起動し、UIA・キーボード・実IMEの3経路を検証する。

未実装の必須機能を後続範囲へ移してv1.0を成立させない。
商用製品に対する優位性は未達。一般的な復元率や、すべての有料製品を上回るとは主張しない。
元データがない通常利用では、構造検証や出力ハッシュを削除前との同一性の証明と表示しない。
