# Rescue v1.23.0

原本の長さとSHA-256から、等間隔に分かれたファイルを復元できます。先頭が分からないときは断片の間隔を指定します。先頭位置が分かるときは、間隔の上限を指定して前後両方向を探せます。GUIでは「原本のSHA-256でファイルを復元」で「等間隔に分かれた断片を検索」を選びます。

次の例では1断片を512バイトとし、断片の先頭間隔を1,024バイトに指定しています。原本のバイト数とSHA-256は削除前の記録から指定します。

```sh
rescue recover-by-hash --source disk.raw --output recovered.bin --file-bytes 5901 --sha256 "$ORIGINAL_SHA256" --run-blocks 1 --stride-blocks 2 --json
```

## 照合結果

| 試験 | 原本と一致した件数 |
| --- | ---: |
| FAT12・FAT16・FAT32で実際に削除した7種類、各3〜10断片 | 間隔指定と間隔探索で各21/21 |
| 管理情報を消した35形式の比較用イメージ、1セクターおきの配置 | 間隔指定と間隔探索で各36/36 |
| 同じ比較用イメージで元データ全体を上書き | 各0/36、保存なし |

前後の配置、短い最終断片、未取得範囲、探索量の上限も検証しました。原本と全バイト・SHA-256が一致しているかを確認し、FATの実削除では、削除前に記録した物理位置とも照合しました。[ファイル別の検証記録](STRIDED-RECOVERY.md)

Linuxの実GUIでも実際に削除したFAT12の7件、計29,634バイトを復元しました。4件は先頭不明で間隔を指定し、3件は先頭位置から間隔を探索しました。誤ったSHA-256を指定した試験では出力が作成されませんでした。通常の画面からの18アーカイブ復元、CSV・HTMLレポート、および64 MiBの取得中断・再開も確認しました。[GUIの照合記録と画面](gui-v1.23-results.json)

Linuxリリースビルドで統合試験80群、Rustのテスト96件、35形式の回帰試験1,116観測を実行しました。回帰試験は1,016観測でバイト一致し、欠損や上書きなどの条件別結果を含めて試験を通過しました。

## 適用範囲

原本のSHA-256と長さが必要です。最後を除く断片長と隣接する断片の間隔は一定で、各領域に重なりがないことが条件です。最大ファイルサイズは64 MiB、検索は既定で512 MiB分の読み取りまでです。保存の直前に候補を再度読み、SHA-256が一致した場合に出力を確定します。上書き、TRIM、未取得のバイトはこの検索で再現できません。

RAW、対応する読取マップ付きRAW、組み立て済みの対応RAIDは追加ツールなしで照合できます。暗号化された媒体は平文を読み出せる状態にする必要があります。実削除試験を再現する際はmtoolsを使用します。[CLIとGUIの操作、ブロック境界と上限](IMAGING.md)
