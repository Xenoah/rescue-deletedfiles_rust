# 見やすさと配色

画面右上の「配色」で「ライト」「ダーク」「システム」を切り替えます。
「システム」はOSの配色に従います。処理中も切り替えでき、次回起動時も選択を引き継ぎます。

本文は16px、補足は14px、主操作ボタンは高さ44pxを基本にしています。
スキャン中は進捗率、読み取り量または解析レコード数、候補数、読み取り元をまとめて表示します。
中断・保存と取消は画面下部に常時表示します。

設定の不足・誤りがある状態で「スキャン開始」を押すと、処理を開始せず、
該当欄を赤枠と「要確認」の説明で示します。最初のエラー箇所までスクロールし、
詳細設定内のエラーはその設定を展開して表示します。
数値・拡張子などの入力エラーは編集中も確認し、修正すると赤枠を解除します。
パスの存在や種類は開始時に確認し、実際のアクセス権やデバイスの読み取りはエンジンで確認します。

配色だけを次の設定ファイルに保存します。復元データや入力パスは保存しません。

- Windows: `%APPDATA%/Rescue/appearance.json`
- macOS: `~/Library/Application Support/Rescue/appearance.json`
- Linux: `$XDG_CONFIG_HOME/Rescue/appearance.json`（未指定なら `~/.config/Rescue/appearance.json`）

検証にはGUIのキーボード・アクセシビリティ・ウィンドウサイズの回帰テスト、
配色の文字コントラスト、入力チェック、設定の保存・再読込テストを使用しています。
