# Rescue v1.47.0

ASF、WMA、WMVの連続した音声・映像をディスクイメージから抽出できます。固定長パケットを持ち、ファイルの長さが記録されているASFが対象です。音声・映像のストリーム情報を読み、WMA音声、WMV映像、その他のASFを区別します。通常スキャン、索引スキャン、GUIから利用できます。復元するだけならメディアコーデックのインストールは不要です。

```sh
rescue scan --source image.raw --mode carve --extension wma --extension wmv --extension asf --work-dir scan --json
rescue recover --session SESSION --all --destination recovered --json
```

`--extension wma` はWindows Media音声だけを、`--extension wmv` はWindows Media映像を含むファイルを選びます。`--extension asf` だけを指定すると、対応するすべてのストリーム構成を汎用の拡張子 `.asf` で保存します。既知の原本のSHA-256があれば、復元後に `rescue match-hashes` で照合できます。

## 実証結果

FFmpegとGStreamerで12本の原本を用意しました。WMAv1、WMAv2、WMV1、WMV2、PCM、MP3、MSMPEG4v3の7コーデックを含みます。FAT32とext4に各12本を書き込み、読み戻してから削除し、復元した全バイトとSHA-256をファイルごとに照合しました。[原本と再現手順](../tests/asf/README.md) · [Linuxの実測記録](asf-native-results.json)

| 復元方法 | FAT32 | ext4 |
| --- | ---: | ---: |
| 連続領域の通常スキャン | 12/12本一致 | 10/12本一致 |
| 連続領域の索引スキャン | 12/12本一致 | 10/12本一致 |
| ファイルシステム情報を使用 | 12/12本一致 | 12/12本一致 |

FAT32は削除時にクラスターチェーンを消去しました。12本とも既定では候補を復元不可とし、`--estimate-fat-contiguous` を明示して構造を検証すると全バイトが一致しました。ext4では2本の末尾ブロックがスパースで、ディスク上で隣のファイルの先頭に接していました。連続領域の検証は2本を拒否し、Sleuth Kitを使う `rescue filesystem --fs-type ext4` ではゼロ領域も含めて復元できました。復元した音声・映像15ストリームをFFmpegでデコードし、原本を同じ環境でデコードした非圧縮PCM・RGBと全バイトを比較しました。

連結イメージでも原本12本すべてを通常・索引両方式で復元しました。ヘッダー、ストリーム、パケット、索引の破損、暗号化フラグ、実際のライブ配信用ASF、記録範囲内の未読領域など36条件で復元を拒否しました。ファイル終端の直後に未読領域がある場合は完全なファイルを復元できました。構造上有効なタイトルの書き換えは既知の原本ハッシュとの照合で検出しました。[移植可能な試験の記録](asf-results.json)

LinuxのGUIで同じ12本を一括選択してZIPに復元し、展開した251,394バイトと各SHA-256を原本に照合しました。音声・映像の照合はFFmpeg 7.1.5とUbuntu 22.04のFFmpeg 4.4.2で別々に実施しました。両環境でファイル別の復元結果、デコード一致件数、異常系の結果が一致しました。[GUIの試験記録](gui-v1.47-results.json)

Linuxのリリースビルドで107組の統合試験、Rustで96件のテストに成功しました。既存の35形式・36原本による回帰試験は1,116件の期待値に一致し、うち1,016件で原本全体と一致しました。

## 対応範囲

連続領域の検証上限は1ファイル64 MiB、ヘッダー4 MiB、固定長パケット16～65,536バイトです。ファイルとデータの識別子・長さ、ストリーム番号、パケット数、ペイロードの境界、ゼロ詰め、単純索引のパケット参照を検証します。

ライブ配信、暗号化、可変長パケット、未対応のオブジェクト・ペイロード拡張、欠落した中間領域、断片化したファイルは連続領域の検証対象外です。ファイルシステムに有効な配置情報が残っていれば、その情報による復元を利用できます。ASFの構造だけではメディア内容の改変や原本の同一性は判定できません。読み出せないセクタや上書き済みの元データの復元は保証できません。
