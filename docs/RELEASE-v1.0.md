# Rescue v1.0.0

Windows・Linux・macOS向け、初回安定版です。GUI・CLI・MCPが同じRust製エンジンを使い、
NTFS/FAT32/exFATの管理情報復元、PNG/JPEG/PDF/ZIP/Office/MP4/MOVの対応プロファイル、
消失領域の探索、読取マップ付きイメージ取得、RAID 0/1/5/6/10/JBOD、
ディスク索引と再開、PNG/JPEG/テキストの隔離プレビューを提供します。

取消直後にGUIがエラー画面へ戻り、再開操作を失う問題を修正しました。
保存したチェックポイントを独立した検索処理で開き、選択したファイルと再開ボタンを保持します。
この不具合の回帰試験と、実GUIでの3回の取消・再開を追加しました。
Windowsでは作業領域に合わせて最大化して起動し、小さい画面で最下部がタスクバーに隠れる問題を防ぎます。
また、日本語IMEの取消後に未確定文字が残る問題を修正しました。取消通知を受けた入力欄の
未確定部分だけを消し、確定済み文字と次の変換を保持します。

## 実測と商用比較

- Linuxの実GUIで論理1 TiB・1,000万候補を新規スキャン。3回の取消・再開込み623.01秒、
  製品プロセスのピーク141.2 MiB。取消は104〜107 ms。
- 1,000万候補で、入力から実描画までのp95は選択112.11 ms、検索140.01 ms。
  CLIの11検索条件×20回は全220回の候補IDと順序が一致し、p95の最大27.08 ms。
- 同じ固定イメージをUFS Explorer Standard Recovery 10.23、DMDE 4.4.4と比較。
  NTFS/exFATは各製品36/36件一致。削除でFATチェーンが消えたFAT32は
  Rescueが14/36、比較2製品が36/36でした。失敗・未対応を分母から除いていません。

大容量入力は約9.54 GiBの実領域を持つ疎ファイルで、物理媒体1 TiBの全読出し速度ではありません。
商用比較は小さい36ファイルの品質比較です。商用製品の速度、実SSD/HDD、大ファイル、
RAIDや故障媒体での比較は未測定で、「有料製品を超えた」とは主張しません。
`PERFORMANCE-v1.md`、`COMPARISON-v1.md`、各JSONと`comparison-evidence-v1.tar.gz`に
製品・版・設定・ライセンス条件、固定入力、実出力、再採点手順を収録しています。

## 検証と配布

Windows x64、Linux x64、macOS Intel/Apple Siliconの4ネイティブVMで、
Rust試験、27統合試験群、破損入力の決定的変異fuzz、実OSの仮想ディスク・削除・
元の場所への復元、梱包後のCLI/MCPとGUI起動を検証することを公開条件にしています。
Windowsは実GUIが非昇格・中整合性・管理者グループ無効であることを検査し、UIA操作とネイティブキー入力で
日本語のPDF/テキスト2件1,428バイトをZIP復元する試験も必須です。
実Microsoft日本語IMEのローマ字入力、予測候補と未確定文字の取消、漢字への変換・確定も検証します。

各OS/CPUにインストール版とポータブル版、計8パッケージがあります。
全添付ファイルのチェックサムは`SHA256SUMS.txt`、梱包・検証記録は
`package-*.json`、`verification-*.json`と各機能の結果JSONを参照してください。
公開後は同じポータブルを4環境で再取得して実行し、追加結果と
`PUBLISHED-SHA256SUMS.txt`を添付します。

macOSはアドホック署名で、Appleの公証はありません。Windowsの発行元署名はありません。
旧GUIの専門機能の画面はalpha.15/alpha.16の版表示を保持し、
`gui-evidence-carryover.json`でv1.0の新規画面と区別しています。
`intelligence.html`は画像を内蔵した、オフラインで操作できる技術説明です。

## 対応の境界

上書き・TRIMで失われたバイトは復元できません。構造検証や保存後のSHA-256だけで、
削除前の正解との一致を保証しません。欠損範囲をバイナリ書き出しした場合は未検証と表示します。

FATチェーンを失った複数クラスタの推測、断片化carvingの再構成、EFS、TexFAT、
PDFのxref stream/暗号化、fragmented MP4等は未対応です。
APFS/ext4、FAT12/16、ReFS、VHD/E01の直接入力、PDF/Officeプレビューはv1.1以降の範囲です。
対応プロファイルと資源上限は`ALPHA.md`、`BACKLOG_V1_1.md`と各機能の説明を参照してください。

WindowsのIMEは、イベントのモデル試験に加え、実Microsoft日本語IMEを操作しています。
UIAによる自動操作と読み上げ製品の手動評価は区別しています。
読み上げ製品、人が操作するUAC同意画面の評価は未実施です。
