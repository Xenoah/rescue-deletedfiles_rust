# Rescue v1.35.0

JPEG 2000のJP2画像と、コンテナに格納されていないJ2Kコードストリームを連続領域から復元できます。GUIの「Carving」で拡張子に `jp2`・`j2k` を指定します。CLIでは次のように検索できます。

```sh
rescue scan --source disk.raw --mode carve --extension jp2 --extension j2k --work-dir scan --json
```

通常スキャンと索引スキャンは、寸法・色成分、タイルの境界、符号化パラメーター、終端を確認し、全タイルをRustの内蔵デコーダーで展開します。両方の拡張子を指定した場合、検証済みのJP2は1件として表示されます。J2Kだけを指定すると、JP2に内包された有効なコードストリームも単独で取り出せます。J2Kの検索には `jpc` と `j2c` も使えます。

## 実際に削除した画像

OpenJPEG・FFmpeg・macOSのApple ImageIOが生成した白黒8ビット・16ビット、RGB、RGBA、可逆・非可逆圧縮、複数タイル・複数品質レイヤーなどの画像を使いました。XML・UUID・空き領域ボックス、64ビットの長さ、最後のコードストリームボックスの長さを0とするJP2も含みます。

| 検証した経路 | 結果 |
| --- | --- |
| FAT32で書き込み・読み戻し・実削除 | 21/21件で原本の全バイトとSHA-256が一致 |
| ext4で書き込み・読み戻し・実削除 | 21/21件で原本の全バイトとSHA-256が一致 |
| 通常・索引スキャンから個別に復元 | 両ファイルシステムで全画像のOpenJPEGによる復号画素が原本と一致 |
| Linux GUIからFAT32を再スキャンしてZIPに保存 | 21件・248,648バイトが原本と一致 |
| 破損した構造・対象外の符号化 | 44例すべてで対象画像の復元を拒否。読取不能セクターをまたぐコードストリームも拒否 |

Apple ImageIOで書き出した6画像では、グレーとRGBのICC v2プロファイルを保持し、LittleCMSで原本と復元画像をsRGBに変換した結果も比較しました。可逆圧縮の3点ではApple ImageIOとOpenJPEGの復号画素がすべて一致しました。非可逆圧縮の3点では、両デコーダー間に8ビット成分あたり最大1の差がありました。[macOSでの生成と読み戻し](https://github.com/Xenoah/rescue-deletedfiles_rust/actions/runs/44672922457)

有効なJPEG 2000コメントを1バイト変更した対照試験では、画像は正常に展開されました。復元レポートを原本のSHA-256と照合すると不一致となりました。画素の復号成功だけではファイル全体の同一性を証明できません。[原本別の測定値](jpeg2000-results.json) · [生成条件と画素のSHA-256](../tests/jpeg2000/manifest.json) · [GUIの測定値](gui-v1.35-results.json)

## 対応範囲と制限

- 対象はPart 1の単一画像で、符号化データは64 MiBまで、幅と高さは各8,192画素まで、全成分のサンプル数は合計4,194,304までです。同じ精度の符号なし1〜16ビット、等倍サンプリング、最大4成分、1,024タイル、各タイル1パート、最大16品質レイヤー・8分解レベルを扱います。
- スタンドアロンのJ2KはEOCを終端とします。JP2は長さが確定するXML・UUID・freeの付加ボックスを保存します。未知の末尾データ、分断されたエクステント、上書き済み・未取得領域はカービングで補えません。元のファイル名・削除の有無はディスクの管理情報から別途確認する必要があります。
- JPX、MJ2、HTJ2K、LUT型ICC・ICC v4、パレット、成分ごとの異なる符号化、複数タイルパート、オフセット付き格子には対応していません。有効なコードストリームが独立して残っていれば、J2Kだけを検索して取り出せる場合があります。
- 内蔵のICC検査は、JP2の制限付きグレースケール曲線およびRGB行列・階調曲線プロファイルについて、ヘッダー、タグ範囲、共有領域、必須タグ、曲線長を照合します。復元時に外部の色変換ソフトは不要です。今回の原本生成と画素の照合にはApple ImageIO、OpenJPEG、FFmpeg、LittleCMSを、ファイルシステムの作成・削除と削除記録の確認にはdosfstools、mtools、e2fsprogs、The Sleuth Kitを使用しました。
