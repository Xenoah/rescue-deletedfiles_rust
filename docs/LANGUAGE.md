# 画面の言語

初期言語は日本語です。画面上部の **Language** で英語に切り替えられます。
`rescue-gui --language en` で英語で起動し、`--session FILE` と組み合わせることもできます。

設定・検索・取得・RAID・索引・復元・プレビューの操作を切り替えます。
ファイル名、パス、検索語、選択した候補、元媒体の警告、OSやエンジンの詳細エラーは元の値を保持します。
JSONのフィールド名やエラーコード、媒体、保存済みセッションは変更しません。

非同期処理の完了メッセージは両言語を保持し、表示時に選びます。
引数は一度だけ評価するため、レポート保存などの処理を翻訳のために二重実行しません。
単体検証ではスレッドをまたぐ結果、入れ子の言語切替、引数の一回評価、日本語パスを確認しています。

[実GUIの記録](gui-i18n-results.json)では、英語で36候補をスキャンし、PDFとテキストを検索して選択しました。
日英切替を挟んで2件1,428バイトをZIPへ復元し、独立した正解データ、日本語の名前、元媒体の不変を照合しました。
100/150/200%のレイアウトと720×520の実画面も確認しています。

この検証中、列幅変更の境界に見えないTab停止箇所を発見しました。キーボード操作のレビューで修正します。
Windows UIA、実IME、実OSのDPI検証は[受入台帳](V1_ACCEPTANCE.md)で別途追跡します。
